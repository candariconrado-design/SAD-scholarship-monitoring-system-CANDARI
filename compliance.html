Compliance Overview

This page shows scholars with their latest status after verification.

Compliance Rule (documented): Lower GWA is better. A scholar is Compliant only if:

  • GWA ≤ required_gwa of the assigned scholarship
  • Units enrolled ≥ min_units
  • Failed subjects = 0 (unless the program allows failing grades)
